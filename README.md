# 提肛小助手

一个显示在 VS Code 状态栏上的提肛练习计时器。

## 功能

- 点击状态栏中的 `🧘` 按钮开始一组练习。
- 默认节奏：收紧 4 秒 → 放松 4 秒。
- 每完成一次收紧，今日次数加 1。
- 默认每完成 20 次收紧计为 1 组，完成一组后自动停止。
- 今日次数和组数会保存在 VS Code 中，重启后仍然保留。
- 按本地日期自动切换；进入新的一天后统计清零。
- 可通过命令面板执行“提肛小助手：清零今日统计”。

## 使用方式

1. 用 VS Code 打开本目录。
2. 按 `F5` 启动扩展开发宿主窗口。
3. 点击右下角状态栏中的 emoji 按钮开始练习。
4. 练习中再次点击同一个状态栏项目可提前停止；完成一组后会自动停止。

组数规则可以在 VS Code 设置中修改：

`提肛小助手 › Repetitions Per Set`

也可以在 `settings.json` 中配置：

```json
{
  "tigangHelper.repetitionsPerSet": 20,
  "tigangHelper.phaseDurationSeconds": 4
}
```

## 打包安装

安装 `@vscode/vsce` 后，在本目录执行：

```powershell
vsce package
```

随后在 VS Code 的扩展页面中选择“从 VSIX 安装”。

> 本扩展仅提供计时和记录功能，不构成医疗建议。如有疼痛或不适，请停止练习并咨询专业人士。
